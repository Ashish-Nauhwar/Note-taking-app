# 📓 NoteKeeper

NoteKeeper is a full-stack, responsive note-taking web application built using the MERN stack (MongoDB, Express, React, Node.js). It provides users with a clean dashboard layout to seamlessly handle CRUD operations (Create, Read, Update, Delete) on their notes in real time.

---

## 🚀 Key Features
- ⚡ **Full CRUD Functionality**: Seamlessly create, view, update, and remove notes dynamically without full page reloads.
- 🕒 **Chronological Feed**: Automatically sorts notes showing the most recent ones first via MongoDB timestamps.
- 🎨 **Modern Interface**: Custom-styled UI utilizing responsive Tailwind CSS utility grids and dark-mode aesthetic features.
- 🔒 **Data Validation**: Strict backend data validation schemas with automated payload trimming via Mongoose.
